# /goal-contract — Claude Code Skill

Пишет текст `/goal`-контракта для ограниченного автономного прогона: критерии приёмки, условия NO-GO и защиту от подгонки результата — из решений, уже принятых в разговоре.

## Как работает

```
/goal-contract
```

Скилл выдаёт готовый текст контракта и останавливается. Запускает его человек: запуск и есть одобрение, а отправленный текст (с правками) и есть контракт.

## Главные правила

- **Оба исхода терминальны.** NO-GO с названным блокером закрывает цель так же полно, как PASS.
- **Каждый критерий проверяем внутри прогона.** Всё, что требует покупки, чужого решения или недоступного ресурса, — это условие NO-GO, а не критерий.
- **Защита от подгонки называет конкретный побочный эффект**, а не «не жульничай».
- **Вопрос без ответа — NO-GO, а не диалог.** Интерактивные вопросы запрещены.
- **Критерий, невыполнимый «как написано», — конец прогона, а не повод крутиться.**
- **Одна цель — одна стадия.** Паузы «подожди моего одобрения» внутри цели не работают.
- **Различающее наблюдение вместо агрегата.** Код возврата, «зелёный конвейер», «0 ошибок» склеивают разные исходы; критерий должен быть наблюдением, которое их разделяет.
- **Контракт до ~1500 символов, итоговый отчёт короткий** — иначе проверяющий не вместится в контекст.
