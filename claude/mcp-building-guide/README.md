# /mcp-guide — Claude Code Skill

База знаний для разработки MCP-серверов. Best practices из анализа 50 production-серверов.

## Как использовать

```
/mcp-guide
```

Скилл загружает полное руководство по разработке MCP-серверов в контекст Claude. При разработке MCP-сервера агент автоматически применяет best practices.

## Что внутри

На основе анализа 50 production MCP-серверов от Stripe, Sentry, GitHub, Cloudflare, Supabase, Linear, Figma, Datadog, Grafana, Playwright, AWS, Terraform, Kubernetes, MongoDB и других.

**Часть I — Архитектура и протокол**
- Обзор архитектуры MCP, модели развёртывания
- Транспорт STDIO и StreamableHTTP
- Дерево решений по выбору транспорта
- Авторизация: OAuth 2.1 и альтернативы

**Часть II — Проектирование tools**
- Конвенции именования из индустрии
- Описания tools для LLM
- Управление количеством tools (от 1 до 1400+)
- Tool Annotations для безопасности

**Часть III — Паттерны реализации**
- Архитектура сервера и структура кода
- Обработка ошибок (паттерны Sentry, Grafana, Supabase)
- Безопасность и защита от prompt injection
- Оптимизация расхода токенов

**Часть IV — Продвинутые возможности**
- Sampling: делегирование LLM-вызовов клиенту
- Resources и Prompts
- Логирование и прогресс-нотификации
- Roots: контроль доступа к файловой системе

**Часть V — Эксплуатация**
- Отладка через MCP Inspector
- Тестирование: LLM Evals
- Развёртывание: Docker и CI

**Часть VI — Индустриальные паттерны**
- Сводная таблица: 20 ключевых MCP-серверов
- Топ-35 паттернов из production
- Чеклист перед релизом

## Установка

1. Скопируйте папку `mcp-guide-skill` в `.claude/skills/` вашего проекта
2. Запустите `/mcp-guide` в Claude Code

Конфигурация не требуется — это read-only база знаний.
