# UX Reviewer

Custom GPT для анализа UI-скриншотов и поиска UX-проблем.

## Что делает

- Анализирует скриншоты интерфейсов
- Находит UX-проблемы через призму AJTBD, эвристик Нильсена, когнитивных законов
- Предлагает quick wins и стратегические улучшения
- Оценивает влияние на продуктовые метрики

## Как использовать

1. Создай Custom GPT в ChatGPT
2. Скопируй содержимое `instructions.md` в поле Instructions
3. Загрузи `knowledge.md` как Knowledge file

## Файлы

- `instructions.md` — системный промпт для GPT
- `knowledge.md` — база знаний (UX-фреймворки, паттерны, антипаттерны)
