# ATJBD — Product Strategy & JTBD Architect

Custom GPT для разработки продуктовых стратегий по методологии Advanced Jobs To Be Done.

## Что делает

- Помогает находить точки кратного роста
- Валидирует идеи через юнит-экономику
- Анализирует через призму "убийства работ"
- Строит маршрут AS IS → TO BE

## Как использовать

1. Создай Custom GPT в ChatGPT
2. Скопируй содержимое `instructions.md` в поле Instructions
3. Загрузи `knowledge.md` как Knowledge file

## Файлы

- `instructions.md` — системный промпт для GPT
- `knowledge.md` — база знаний (стратегия + AJTBD)
